# 푸른 밤 플레이 UI

사용자 기린·달·떠 있는 성 참조를 내장 ImageGen으로 재구성했다.
`night-background.png`에는 보석·보드·HUD가 없고, `night-hud-atlas.png`에서
Unity가 카드·아이콘·버튼 스프라이트를 UV로 잘라 사용한다. 원본 PNG는 보존한다.
`UiThemeImport.cs`가 참조용 `.asset`과 `.meta`를 생성한다.

제작 프롬프트: 참조의 사파이어빛 밤하늘, 달, 기린과 등불, 떠 있는 성, 꽃을 보존한다.
카드와 타이머, 폭탄·해머·무지개·셔플 버튼은 글자·숫자 없이 광택 파란색으로 만든다.
기존 보드가 올라올 중앙은 비워 두며, 배경에는 게임 보석과 보드를 그리지 않는다.
별도 배경 판에서는 모든 UI를 제거하고 같은 장면을 자연스럽게 이어 그린다.

보석 텍스처, 보드 칸 수와 게임 규칙은 유지한다. 보드 표시 크기는 안전 영역의 가로폭과 남은 세로 공간에서 결정한다.
폰에서는 가로폭의 약 91%를 사용하고, 태블릿·폴드는 목표 카드와 일시정지를
한 줄로 압축해 정사각 보드의 높이를 확보한다. 아이템 네 개는 보드 아래 중앙에 정렬하고, 현재 던질 조각만 오른쪽에 표시한다.
다음 조각은 내부 큐만 유지하며 미리보기는 숨긴다. 스테이지 표시는 그 아래에 배치한다.
배경은 전체 화면을 덮는 한 장만 표시한다. 같은 풍경을 중앙에 중복 렌더링하지 않는다.
일시정지 버튼은 확대된 HUD의 상단에서 충분히 안쪽으로 배치한다.
색상별 목표가 없는 현재 규칙에 임의의 목표 카운터를 추가하지 않는다.
목표 카드에는 기존 스테이지 조건의 문구와 진행률을 표시하며 장식용 보석은 넣지 않는다.
