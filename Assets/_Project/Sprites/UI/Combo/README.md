# 콤보 팝업 아트

`combo-atlas.png`는 사용자 COMBO x3 참조를 내장 ImageGen으로 편집한 투명 아틀라스다.
프롬프트: 분홍·노랑·하늘·초록·보라 COMBO 입체 글자, 파랑·보라 테두리와 보석·별을
상단 40%에 배치한다. 하단 44~100%는 6열 2행으로 금색 0~9와 x를 각각 분리하여
배치한다. 첫 행은 0~5, 둘째 행은 6~9·x·빈칸이다. 검은 배경과 칸 구분선은 제거한다.

Unity가 원본 PNG의 UV를 잘라 참조 스프라이트를 생성한다. `GameUI.SetComboArt`는
실제 연쇄 수를 x3·x5·x12처럼 조합하고 기존 낙하·되튐·반짝임·사라짐 연출을 재사용한다.
아트가 누락되면 기존 Baloo 2 글자 팝업으로 표시한다. 점수와 콤보 판정은 변경하지 않는다.
