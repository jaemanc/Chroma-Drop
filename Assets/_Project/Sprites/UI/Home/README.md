# 홈 메뉴 아트

`home-menu-v2.png`는 사용자 참조 이미지로 내장 ImageGen 도구에서 제작한 UI 아트다.
로고·배경·아이콘·버튼 바탕은 이미지이고, 숫자·버튼 문구·충전 시간은 실제 UI다.
좌표는 `MainMenu.cs`의 정규화된 아트 좌표를 사용한다. 참조는 `ui-theme.asset`에 둔다.

제작 프롬프트: 참조의 파란 하늘·떠 있는 성·보석·왕관 고양이·CHROMA DROP 로고와
리본을 보존한다. 상단 코인·하트·설정, 금색 PLAY, 보라색 RANKING, 초록색 SHOP,
보물상자 광고 배너의 위치와 광택을 유지하고 동적 숫자·버튼 글씨만 제거한다.
스크린샷 검은 테두리 없이 세로 화면 전체를 채운다.

`home-background-wide.png`는 내장 ImageGen으로 같은 메뉴 세계를 넓힌 배경이다.
프롬프트: 원본의 푸른 낮 하늘, 흰색·분홍 구름, 꽃과 폭포가 있는 떠 있는 성을 좌우로
확장한다. 원본 가장자리 색감과 높이별 배치를 유지하고 UI·로고·고양이·보석은 제거한다.
배경은 화면 전체를 덮고 메뉴는 안전 영역 안에 비율을 유지하여 iPad·폴더블 여백을 채운다.
`HomeArtEdgeBlend`가 메뉴 이미지 가장자리 3.5%를 배경에 섞으며 클릭 영역과 글자에는 영향을 주지 않는다.

# 광고 보상 창

`bonus-reward.png`는 사용자 보너스 보상 참조를 내장 ImageGen으로 편집한 투명 스프라이트다.
프롬프트: 고양이·보석·잎·별, 광택 파랑·금색 테두리, 크림색 발바닥 무늬와 코인 더미를
보존하고 바깥 배경을 투명하게 만든다. 배너·금액·설명·닫기 글자는 모두 제거하여 실제
UI 글자로 표시할 공간을 둔다. 금색 하단 버튼은 빈 상태로 유지한다.

홈 광고는 완료 시 100코인 지급, 테스트 광고 중 닫기는 취소다. 실제 광고 SDK 연결은 별도다.
