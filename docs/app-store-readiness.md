# App Store 제출 준비

현재 업로드된 TestFlight 빌드는 변경하지 않았다. 아래 소스 변경은 다음 Unity 빌드부터 반영된다.

## 소스에 반영한 사항

- 상점은 아이템 전용. 코인 구매·스킨 판매 화면 제거, `Iap.Buy`는 출시 더미 주문 생성 차단
- 홈 코인 +: 구매 대신 플레이·광고로 코인을 얻는 안내
- 일반 출시 빌드: 허구 플레이어·국가 랭킹 대신 이 기기의 Easy/Normal/Hard/Time Attack 최고 점수
- 로컬 점수는 광고 시청 없이 저장하며, 출시 기록 화면에는 광고 점수 등록 버튼을 표시하지 않음
- 코인 자동 10만 지급과 5회 터치 지급 제거. 더미 결제 서비스·랭킹은 에디터·개발 빌드에만 유지
- 기존 코인·아이템·스킨 JSON과 점수 키는 유지. 원격 랭킹을 다시 켜지 않음
- 개인정보처리방침 HTTPS URL을 설정하면 홈 설정 메뉴에 연결
- `.env`의 `useTestAds`로 운영 광고 전환 가능. 기본 true이며 이번에는 운영 광고로 바꾸지 않음

## 아직 필요한 사항

1. 운영자·문의 이메일과 광고 데이터 처리를 확정하고 개인정보처리방침을 공개
2. 공개 URL을 `Assets/Resources/app-info.json`과 App Store Connect에 입력
3. 실제 광고 수집 항목에 맞게 App Store 개인정보·연령 등급 입력, 추적을 사용하면 ATT 구현
4. 실기기에서 출시 UI, 광고 완료·취소·실패 및 코인/하트 지급 확인
5. 현재 버전 설명과 스크린샷에서 온라인 순위·실제 코인 구매 기능을 약속하지 않기
6. 인앱결제를 출시하려면 별도 SDK·상품 등록·서버 검증·중복 방지·미지급 복구 구현
7. UnityRuntime dSYM 경고는 업로드를 막지 않지만 해당 UUID의 심볼 확보 전까지 엔진 충돌 분석에 제한

`TestServices.Enabled`만 꺼서는 결제가 구현되지 않으며 기존 로컬 저장 경로도 바뀌므로 금지한다.
테스트 통과나 컴파일 성공을 Apple 심사 승인 또는 실기기 검증 완료로 해석하지 않는다.
